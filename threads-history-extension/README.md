# Threads 觀看紀錄（Chrome MV3）

這是一個本機使用的 Chrome 擴充功能。記錄你真正看過的 Threads 貼文，以及進入貼文詳情頁後看過的其他貼文／回覆。支援 `threads.com` 與舊 `threads.net` 網域。

## 安裝（Windows / macOS / Linux）

1. 解壓縮 ZIP；Chrome 無法直接「載入未封裝項目」選取 ZIP。
2. 開啟 Chrome 並輸入 `chrome://extensions`。
3. 打開右上角「開發人員模式」，選「載入未封裝項目」。
4. 選擇解壓縮後**含有 manifest.json 的資料夾**。
5. 重新整理 Threads 分頁，開始正常瀏覽。
6. 點 Chrome 工具列的擴充功能圖示，可開啟完整觀看時間軸。

## 規則與資料模型

- **觀看成立**：頁面是目前作用中的可見分頁，貼文卡片可見比例至少 52%，並且連續可見至少 1.5 秒（可調）。
- **避免重複**：同一個貼文代碼只存在 `posts` 一筆；每次真的觀看，新增一筆 `events`。同篇貼文必須離開畫面至少 3.2 秒，且距上一次紀錄至少 45 秒，才會新增下一次觀看。
- **打開貼文**：直接開貼文詳情頁、在站內切換到貼文頁時，也另記一筆 `open` 事件（與達到可見門檻的 `view` 不同）。
- **留言**：在 `/@作者/post/代碼` 的貼文詳情頁中，根貼文以外的獨立貼文卡片視為「留言串內貼文」，記成 `reply` 事件。回覆其實也有自己的 permalink，所以依自己的貼文代碼去重。注意：站內推薦貼文如果混排在詳情頁，可能被視為留言串內容；這類回覆關係無法完全靠 DOM 保證。
- **只存本機**：IndexedDB 存 `posts` 和 `events`。不讀 Cookies、不攔截 API、不發出外部網路請求、不上傳資料；`chrome.storage.local` 只存偏好設定。
- **全文**：盡可能擷取可見 DOM 內文（最多 2200 字），不保存圖片檔。圖片貼文沒有文字摘要時仍記 URL。
- **時間**：事件時間取使用者目前瀏覽器的裝置時間，與貼文的原始發文時間分開。
- **匯出**：JSON（貼文／事件完整結構）、CSV（依事件一列，Excel 可開）。

## 限制

- Threads 網頁經常改 DOM 結構：`content.js` 中的卡片選取邏輯可能需隨改版調整。本版已覆蓋多種通用 DOM 結構，但**尚未在你的 Threads 登入帳號上做實際驗收**。
- 不會回溯安裝前的觀看內容；不支援手機 App、其他瀏覽器或另一台電腦的紀錄同步。
- 私密帳號或刪除貼文的既有本機文字摘要仍保留，直到你手動清空。
- 對極快速捲動、沒有 permalink 或沒有正常時間戳的特別卡片可能漏記。只記錄在畫面上已渲染的留言，不能保證把留言串全部保存。
- 「在貼文詳情頁出現的非根貼文」按頁面上下文標為留言，無法完全驗證它與根貼文的真實回覆關係。
- 關閉此擴充功能前若仍在當前頁面，已偵測但尚未成功寫入的短暫佇列可能遺失；已寫入 IndexedDB 的資料不會因此消失。

## 架構

- `manifest.json`: MV3 最小權限與內容腳本網域。
- `core.js`: URL、文字與可視區域／重看判定工具。
- `content.js`: SPA 導航、可視性、停留門檻與批次事件。
- `background.js`: 驗證訊息、排除非 Threads 來源、寫入本機資料。
- `db.js`: 擴充功能 origin 的 IndexedDB，跨分頁安全、原子更新。
- `popup.*`: 快速開關及最近紀錄。
- `dashboard.*`: 搜尋、日期篩選、歷史詳情、匯出、清空、設定。

## 開發測試

在專案根目錄執行 `node tests/test-core.js` 驗證共用功能。若要查看是否有擷取，請登入 Threads 並保持貼文至少 1.5 秒，然後檢查擴充功能的完整時間軸。變更內容腳本後，需在 `chrome://extensions` 重新載入擴充功能並重新整理 Threads。
