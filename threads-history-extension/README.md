# Threads 觀看紀錄（Edge / Chrome MV3）

這是一個本機使用的 Edge / Chrome 擴充功能。**只要 Threads 已經載入 DOM 內的貼文或留言，就記錄下來**，包含未實際捲動到的預載項目。支援 `threads.com` 與舊 `threads.net` 網域。

## 安裝（Windows / macOS / Linux）

1. 解壓縮 ZIP；Edge/Chrome 無法直接「載入未封裝項目」選取 ZIP。
2. 開啟 Edge 並輸入 `edge://extensions`（Chrome 為 `chrome://extensions`）。
3. 打開右上角「開發人員模式」，選「載入未封裝項目」。
4. 選擇解壓縮後**含有 manifest.json 的資料夾**。
5. 重新整理 Threads 分頁，開始正常瀏覽。
6. 點 Chrome 工具列的擴充功能圖示，可開啟完整觀看時間軸。

## 1.2.0 規則與資料模型

- **載入即記錄**：只要 Threads 的 DOM 已載入貼文／留言卡片，立即新增紀錄。不必等待、也不要求在畫面可視範圍內。Threads 預先載入但你未真正看見的貼文也可能被記錄。
- **去重**：同一篇貼文以 permalink ID 合併貼文主檔；同次站內導航同篇只建立一筆觀看事件。新導航或重新整理可以再次建立事件；延遲載入圖片只會更新媒體，不增加觀看次數。
- **圖片保存**：從貼文／留言中擷取已完成載入的大圖和影片封面；嘗試下載至該瀏覽器設定檔的 IndexedDB，圖片若受 CDN 阻擋則仍保留圖片 URL。為避免混淆，忽略小圖、頭像和圖示（但此判斷不保證完美）。
- **貼文畫面截圖**：只在 Threads 分頁是目前作用中視窗時，嘗試把螢幕上已顯示的貼文卡片裁切存成本機 WebP；不在畫面上的貼文仍有文字及圖片，但沒有截圖。畫面只截當下可見部分，不做長圖拼接。截圖頻率受限，每篇貼文最多保留一張。
- **Edge 多使用者設定檔**：每個 Edge Profile 有獨立擴充功能儲存空間。需要在每個 Profile 分別安裝；不會將觀看紀錄跨設定檔同步。
- **資料與權限**：資料在本機 IndexedDB，不主動上傳觀看紀錄。本版因自動截圖需要 Chrome/Edge 的 `<all_urls>` 廣泛主機權限；但內容腳本僅在 threads.com / threads.net 注入，背景程式對截圖來源也驗證 Threads 分頁。請自行評估此廣泛授權。
- **匯出**：JSON / CSV 匯出貼文、事件及媒體 URL；下載的二進位圖片及截圖不包含在 JSON / CSV 中。刪除擴充功能或清空資料會失去已快取圖片。
- **注意**：擴充功能只觀察網頁真正生成的 DOM，不能保證擷取未渲染或尚未載入的內容；網站更動、圖片 CORS/授權、CDN 防護都可能造成漏記。尚未用你的 Threads 帳號及 Edge 版本做實測。

## 架構

- `manifest.json`: MV3 最小權限與內容腳本網域。
- `core.js`: URL、文字與可視區域／重看判定工具。
- `content.js`: SPA 導航、DOM 載入偵測、圖片蒐集、可見卡片截圖請求與批次事件。
- `background.js`: 驗證訊息、排除非 Threads 來源、圖片快取、裁切螢幕截圖、寫入本機資料。
- `db.js`: 擴充功能 origin 的 IndexedDB，跨分頁安全、原子更新。
- `popup.*`: 快速開關及最近紀錄。
- `dashboard.*`: 搜尋、日期篩選、歷史詳情、匯出、清空、設定。

## 開發測試

在專案根目錄執行 `node tests/test-core.js` 驗證共用功能。若要查看是否有擷取，請登入 Threads 並保持貼文至少 1.5 秒，然後檢查擴充功能的完整時間軸。變更內容腳本後，需在 `chrome://extensions` 重新載入擴充功能並重新整理 Threads。
